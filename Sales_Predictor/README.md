# 📈 Sales Prediction Model

A machine learning project that predicts product sales based on advertising budgets using **Linear Regression**.

---

## 🚀 Features
- Data preprocessing & cleaning
- Train/test split with scikit-learn
- Model evaluation using **Mean Squared Error (MSE)** and **R² score**
- Visualization of **Actual vs Predicted Sales**
- User input for predicting sales

---

## ⚙️ Installation
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

---

## ▶️ Usage
```bash
python sales_prediction_model.py
```

When prompted, enter values for TV, Radio, and Newspaper budgets to get predicted sales.

---

## 📊 Example Output
```
📈 Mean Squared Error: 2.10
📊 R² Score (Model Accuracy): 0.91
📦 Predicted Sales for TV=230, Radio=37, Newspaper=69: 22.5
```
